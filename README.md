# SAP Order Report

![Tests](https://github.com/salvatorepenitente-jpg/sap-order-report/actions/workflows/tests.yml/badge.svg)

A Python **transformation and process automation** project that turns SAP sales order data into a daily Excel report, replacing a manual reporting task with a tested, repeatable pipeline.

The project runs on **mock data** and uses standard SAP field names (`VBELN`, `KUNNR`, `AUDAT`, `VDATU`, `NETWR`, `WAERK`, `GBSTK`). The data source is separate from the rest of the code, so it can be connected to SAP without changing the report.

## What the report contains

A file `output/report_ordini_YYYY-MM-DD.xlsx` with five sheets (sheet names are in Italian):

| Sheet | Content |
|---|---|
| **Riepilogo** (Summary) | orders received, total value, comparison with the previous day, late orders |
| **Per cliente** (By customer) | orders and value per customer |
| **Per stato** (By status) | orders and value per status (open, partial, completed) |
| **Ordini in ritardo** (Late orders) | uncompleted orders whose delivery date has already passed |
| **Dettaglio ordini** (Order detail) | all orders of the day, after cleaning |

## Getting started

Requires Python 3.10 or later.

```bash
git clone https://github.com/salvatorepenitente-jpg/sap-order-report.git
cd sap-order-report

python -m venv .venv
source .venv/bin/activate        # on Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # on Windows: copy .env.example .env
python -m sap_report --sorgente mock --data 2026-10-08
```

The report appears in `output/`.

## Data sources

| Source (`--sorgente`) | Status | How to use it |
|---|---|---|
| `mock` | ready | mock data generated by the code, for development and testing |
| `csv` | ready | manual SAP export (e.g. transaction VA05) saved as CSV |
| `odata` | planned (phase 2) | connection to the S/4HANA API `API_SALES_ORDER_SRV` |

To use a CSV export:

```bash
python -m sap_report --sorgente csv --file dati_input/export.csv --data 2026-10-08
```

The CSV must have the columns `VBELN, KUNNR, AUDAT, VDATU, NETWR, WAERK, GBSTK`, with dates in `YYYY-MM-DD` format and a dot as the decimal separator.

## Structure

```
sap-order-report/
├── sap_report/
│   ├── main.py              # entry point
│   ├── config.py            # configuration from environment variables
│   ├── sorgenti/            # where orders come from (data sources)
│   ├── trasformazione/      # data cleaning and KPI calculation
│   └── report/              # Excel file writing
├── tests/
├── .env.example
└── requirements.txt
```

To add a new data source, create a class in `sap_report/sorgenti/` that extends `SorgenteOrdini` and returns a DataFrame with the columns above.
